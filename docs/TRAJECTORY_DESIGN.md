# Trajectory design - v0.2.0

Implemented as an experimental, invisible wave-only preview. Predicts held/released 45-degree movement against nearby static object collision rectangles, trying 0..N frame delays. Does not require previously learned click position on wave. Tested in standalone simulations, not Geometry Dash. Other gamemodes remain reference-based.

Remaining: precise GD physics, object collision polygons, moving hazards, triggers, portals, chained input state, level speed changes, game compatibility and performance validation. Do not claim guaranteed frame-perfect assistance.
